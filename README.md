# 🏢 Priority Handling Logistics, Inc. — Workforce Management Pro

An enterprise-grade, intelligent, and highly secure human resources and workforce management platform. Built for **Priority Handling Logistics, Inc.**, this system integrates **advanced AI biometric verification**, **real-time GPS geofencing & velocity anomaly detection**, **mandatory multi-stage authentication for leadership**, an **embedded Gemini AI Assistant**, and a **multi-tiered HR Leave & Operations Suite** into a modern, responsive web application.

---

## 🌟 The "AI & Intelligence" Advantage

Unlike traditional HR software, this system actively monitors, verifies, and analyzes workforce data to prevent fraud, eliminate buddy-punching, and assist management with real-time operations.

### 1. 👁️ Core Biometric Identity Verification
- **Deep Learning Face Encodings:** When an employee clocks in, their live webcam feed is sent to a dedicated Python AI Microservice running `dlib` and OpenCV.
- **Mathematical Matching:** Extracts 128 unique facial landmarks and compares them against the known, HR-verified encoding stored in the database.
- **Strict Euclidean Tolerance:** Tuned matching algorithm ensures an exceptionally low false-positive rate.

### 2. 🎭 Interactive Liveness Challenges (Anti-Spoofing)
- **Dynamic Challenges:** The UI presents randomized interactive prompts (e.g., "Smile widely", "Turn head left", "Blink").
- **Real-Time Frame Analysis:** Analyzes dynamic micro-motions to ensure the subject is an active, live human, completely preventing photo and pre-recorded video spoofing.

### 3. 📍 Strict GPS Geofencing & Location Lock
- **Device Coordinate Extraction:** Geolocation API extracts precise coordinates during clock-in/out.
- **Haversine Distance Boundary:** Calculates distance against designated organizational site coordinates. Clock-in is strictly blocked if outside the allowed radius.

### 4. 🚀 Velocity-Based Impossible Travel Detection
- **Time-to-Distance Math:** Measures elapsed time and physical distance between consecutive attendance events.
- **Anomaly Flagging:** Automatically flags impossible velocities (e.g., >800 km/h) as `⚠️ SUSPICIOUS LOCATION` for HR audit.

### 5. ⏳ Cryptographic Server-Side Timestamping
- **Database-Enforced Clocking:** Disregards client device system clocks. Timestamps are generated by PostgreSQL (`now()`) at the transaction level, preventing client-side time tampering.

### 6. 💬 Embedded Gemini AI Assistant & Policy Evaluator
- **Conversational HR Querying:** Floating AI Assistant answers operational queries (e.g., "Who is on leave today?", "Summarize late arrivals this week").
- **AI Policy Evaluator for Leaves:** Evaluates employee leave requests against company attendance patterns and policy guidelines with one-click recommendations.

## 🏗️ Comprehensive System Modules

### 📍 1. Command Center Dashboard
- **Global Field Map:** Real-time, dark-themed interactive map (Leaflet) displaying live on-the-clock employees as glowing radar pins.
- **Attendance & Punctuality Leaderboards:** Gamification widget recognizing punctual team members.
- **Real-Time KPI Cards:** Instant metrics for active workforce count, attendance rate, pending approvals, and department distributions with skeleton loading states.

### 🌴 2. Standardized Multi-Stage HR Leave Management
- **Multi-Level Approval Hierarchy:**
  - **Employee Requests:** Submitted to `pending_supervisor` for Team Supervisor review.
  - **Supervisor Endorsement:** Approved requests advance to `pending_hr` for final HR Manager / Admin authorization.
  - **Direct Executive Routing:** Requests from managers bypass intermediate tiers directly to HR.
- **Half-Day Duration Support:** Supports `Full Day`, `Half Day (AM)`, and `Half Day (PM)` with exact `0.5`-day balance deduction logic.
- **Employee Self-Service Cancellation:** Employees can cancel upcoming pending or approved leaves with automatic database balance restoration (`pending_days` / `used_days`).
- **Departmental Overlap Detection:** Automatic visual warning system alerting approvers when other colleagues in the same department have overlapping approved leave dates.
- **Medical Certificate Compliance:** Enforces certificate uploads for sick leaves with integrated viewer and secure document download.

### 👥 3. Employee Directory & Org Hierarchy
- **Interactive Org Chart:** Visual departmental hierarchy showing reporting lines, supervisor chains, and positions.
- **Digital ID Card Generator:** Instant printable CR80 standard employee badge preview with scannable QR and barcode components.
- **Comprehensive Profiles:** Detailed emergency contacts, employment history, compensation rates, and document repositories.

### ⏱️ 4. Timesheet & Automated Payroll Analytics
- **Live Timesheet Auditing:** Auto-aggregated daily work hours, overtime, grace-period late deductions, and break times.
- **Payroll Generation:** Automated calculation of Gross and Net pay tailored for Philippine Peso (PHP ₱) standards with automated CSV export.

### 📅 5. Shift Scheduling & Roster Management
- **Visual Roster Planner:** Interactive shift calendar for assigning individual and recurring team shifts.
- **AI Auto-Scheduler & Health Check:** Analyzes staff workload to prevent burnout and ensure 100% shift coverage across departments.

### 📢 6. Communications & System Notifications
- **Global Notification Bell:** Live push-style updates for pending approvals, timesheet anomalies, and document requests.
- **Company Announcements:** Broadcast banner system with priority tagging and rich content.

## 🛡️ Enterprise Security & Access Control

- **Mandatory Magic Link Multi-Factor Authentication:**
  - Standard employees authenticate with email/password.
  - Higher-up and management roles (`super_admin`, `admin`, `hr_manager`, `team_supervisor`) automatically trigger mandatory, single-use Supabase Magic Link OTPs on login, eliminating password-reuse vulnerabilities for privileged accounts.
- **PostgreSQL Row-Level Security (RLS):** All data is isolated by `org_id` and role permissions at the database engine level.
- **Hardened RPC Functions:** Function execution privileges secured with strict `SECURITY INVOKER` / `REVOKE anon` policies to prevent unauthorized RPC execution.
- **Encrypted Storage:** Biometric landmarks and compliance documents stored in protected, access-controlled Supabase Storage buckets with signed URLs.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ or v20+)
- npm or pnpm
- Supabase Account / Project

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vincenico28/WorkForcePro.git
   cd WorkForcePro
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables:**
   Create a `.env` file in the project root:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
   VITE_GEMINI_API_KEY=your-gemini-api-key
   VITE_API_BASE_URL=https://your-python-ai-service.onrender.com
   ```

4. **Apply Database Migrations:**
   Run migrations via the Supabase CLI or SQL Editor:
   ```bash
   npx supabase db push
   ```

5. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

6. **Production Build & Verification:**
   ```bash
   npm run build
   ```
